# Data export and restore

Wool stores your data locally (and in your private iCloud database when signed
in). You can export a copy at any time from Settings > Data & Privacy.

## Export

- **Export as JSON** creates a backup of tasks, projects, areas, and weekly
  reviews. Save the file somewhere safe (Files, iCloud Drive, email, etc.).
- **Export as CSV** creates a spreadsheet of tasks.

## Restore

1. Open Wool and go to Settings > Data & Privacy.
2. Tap "Restore from JSON".
3. Select the Wool JSON backup file you saved earlier.
4. Confirm. Restoring replaces all data currently on this device with the
   contents of the backup file and then syncs through iCloud when signed in.

## Verifying a backup

Export, erase the app's data (or sign out and clear), then restore. The data
should match the exported backup exactly.
