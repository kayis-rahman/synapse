# Synapse Support

Synapse v1 is a privacy-first, local-first GTD task manager for iOS.

## Getting started

- Capture thoughts into Inbox.
- Triage items into Next Actions, Waiting For, Someday/Maybe, Projects, or Areas.
- Use Today for the daily briefing and Focus for Pomodoro sessions.
- Weekly Review guides a six-step review workflow.

## Known scope for v1

- iOS only.
- Gmail, GitHub Projects, Apple Reminders migration, and Malayalam voice capture are not available in v1.
- English voice capture uses native iOS speech recognition.
- Calendar access is read-only and optional.

## Troubleshooting

- If CloudKit sync is not working, confirm you are signed in to iCloud and have network connectivity.
- If voice capture fails, check microphone and speech recognition permissions in iOS Settings.
- If calendar context is missing, check calendar permission in iOS Settings.
